# Support

*[🇬🇧 Read in English](SUPPORT.md) · 🇫🇷 Français*

> **Knot est en bêta privée.** Le code source vit dans des dépôts privés pendant la bêta. Le moyen le plus rapide de nous joindre est l'email.

## Où poser quoi

| Vous voulez… | Au bon endroit |
|---|---|
| 📰 &nbsp; **Être prévenu·e du prochain lancement public** | Inscrivez-vous via le formulaire sur **[knot.tools](https://knot.tools)** |
| 🧪 &nbsp; **Rejoindre la bêta privée** | Email **`contact@knot.tools`** avec une brève description de votre installation Dolibarr |
| 💡 &nbsp; **Suggérer une fonctionnalité, poser une question, partager un cas d'usage** | **`contact@knot.tools`** — un humain réel le lit |
| 🐞 &nbsp; **Signaler un bug** *(hors sécurité)* | **`contact@knot.tools`** avec : version Knot, version Dolibarr, version PHP, étapes de reproduction, logs expurgés |
| 🔐 &nbsp; **Signaler une vulnérabilité de sécurité** | **`security@knot.tools`** — voir la [politique de sécurité](SECURITY.fr.md) et le [`security.txt`](https://knot.tools/.well-known/security.txt). **N'ouvrez pas d'issue publique.** |
| 📚 &nbsp; **Lire la documentation** | La documentation vit dans les dépôts privés pendant la bêta. Les bêta-testeurs reçoivent une copie packagée. Certains guides sont publiés sur **[knot.tools](https://knot.tools)** au fur et à mesure que le catalogue public s'étoffe. |
| 🤝 &nbsp; **Contribuer du code** | Voir [CONTRIBUTING.fr.md](CONTRIBUTING.fr.md). Les pull requests externes sont reportées jusqu'à la sortie publique de **Knot Core**. |
| 🏷️ &nbsp; **Utiliser la marque ou le logo Knot Tools** | Email **`contact@knot.tools`** avec une description de l'usage prévu. Le brand pack est documenté dans le dépôt **Knot Core** (`img/brand/`). |

## Délais de réponse

- **Accusé de réception de tout email** : sous 72 heures ouvrées, par un humain.
- **Onboarding bêta-testeur** : sous 5 jours ouvrés.
- **Signalements de sécurité** : voir [SECURITY.fr.md](SECURITY.fr.md) — même accusé de réception sous 72 heures, traitement accéléré pour les criticités confirmées.

## Ce que nous ne proposons pas

- **Conseil d'intégration gratuit** à grande échelle. Nous répondons aux questions ciblées mais ne pouvons pas devenir un support SaaS bénévole.
- **Télémétrie**. Nous ne collectons aucune donnée d'usage depuis votre installation. Si vous souhaitez que nous examinions un problème, envoyez vous-même les artefacts pertinents (logs expurgés des secrets).
- **Chat ou appel temps réel** pendant la bêta. Le canal est l'email.
