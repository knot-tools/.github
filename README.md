# knot-tools/.github

Community health files for the **Knot Tools™** organisation. This repository is **not the product** — it only carries:

- `profile/README.md` — public landing page rendered on <https://github.com/knot-tools>.
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `CONTRIBUTING.md` — default community health files inherited by all repositories of the org when no local override exists.

Translations: every policy file is shipped in **English** (default) and **French** (`*.fr.md`).

Product website: <https://knot.tools>.
