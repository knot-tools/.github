# Contribuer à Knot Tools

*[🇬🇧 Read in English](CONTRIBUTING.md) · 🇫🇷 Français*

Merci de votre intérêt pour l'organisation **Knot Tools** sur GitHub.

## Knot Core (public)

**[knot-tools/knot-core](https://github.com/knot-tools/knot-core)** est le module Dolibarr GPL-3.0 d'automatisation visuelle, en **bêta publique** depuis la branche **2.13.x**.

- **Bugs & idées :** [issues GitHub](https://github.com/knot-tools/knot-core/issues/new/choose) sur `knot-core`.
- **Pull requests :** bienvenues sur `knot-core` si le périmètre est clair, testé et documenté — voir le [`CONTRIBUTING.md` du dépôt](https://github.com/knot-tools/knot-core/blob/main/CONTRIBUTING.md).
- **Sécurité :** courriel **`security@knot.tools`** — jamais d'issue publique. Voir [`SECURITY.md`](https://github.com/knot-tools/knot-core/blob/main/SECURITY.md).

ZIP téléchargeable : **[knot.tools/downloads/knot-core/latest](https://knot.tools/downloads/knot-core/latest)**.

## Autres dépôts

| Dépôt | Visibilité | Contributions |
|-------|------------|---------------|
| `knot-core` | Public | Issues + PR |
| `website`, `license` | Privés | Mainteneur uniquement |
| Pro Pack / Migration | Commercial source-available | Achat sur [license.knot.tools](https://license.knot.tools) |

## Code de conduite

Tous les espaces communautaires suivent le [Contributor Covenant 2.1](CODE_OF_CONDUCT.fr.md). Signalements : **`contact@knot.tools`**.

## Refus systématique

- Rapports automatiques sans preuve d'impact reproductible.
- Contributions contenant des secrets, des données client ou des licences non conformes (dérivés n8n, fair-code, BSL, etc.).
