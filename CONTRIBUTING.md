# Contributing to Knot Tools

*🇬🇧 English · [🇫🇷 Lire en français](CONTRIBUTING.fr.md)*

Thank you for considering a contribution to the **Knot Tools** organisation on GitHub.

## Knot Core (public)

**[knot-tools/knot-core](https://github.com/knot-tools/knot-core)** is the GPL-3.0 Dolibarr workflow module, in **public beta** since **2.13.x**.

- **Bug reports & features:** [GitHub Issues](https://github.com/knot-tools/knot-core/issues/new/choose) on `knot-core`.
- **Pull requests:** welcome on `knot-core` when scoped, tested, and documented — see [`CONTRIBUTING.md` in knot-core](https://github.com/knot-tools/knot-core/blob/main/CONTRIBUTING.md) for full conventions.
- **Security:** email **`security@knot.tools`** — never a public issue. See [`SECURITY.md`](https://github.com/knot-tools/knot-core/blob/main/SECURITY.md).

Downloadable ZIP releases: **[knot.tools/downloads/knot-core/latest](https://knot.tools/downloads/knot-core/latest)**.

## Other repositories

| Repository | Visibility | Contributions |

| Pro Pack / Migration | Source-available commercial | Purchase via [license.knot.tools](https://license.knot.tools) |

## Code of conduct

All community spaces follow the [Contributor Covenant 2.1](CODE_OF_CONDUCT.md) (or [French version](CODE_OF_CONDUCT.fr.md)). Report concerns to **`contact@knot.tools`**.

## What we do not accept

- Bulk automated scanner output without a reproducible impact proof.
- Contributions that embed secrets, client data, or non-compliant licences (n8n derivatives, fair-code, BSL, etc.).
