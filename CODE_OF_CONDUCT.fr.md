# Code de conduite

*[🇬🇧 Read in English](CODE_OF_CONDUCT.md) · 🇫🇷 Français*

L'organisation **Knot Tools** a adopté le **Contributor Covenant 2.1** comme code de conduite.

Le texte complet est publié et maintenu par le projet Contributor Covenant :

- **Français** : <https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/>
- **Anglais** : <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- **Traductions** (40+ langues) : <https://www.contributor-covenant.org/translations/>

## Périmètre

Ce code s'applique à tous les espaces opérés par l'organisation **knot-tools** : dépôts GitHub, issues, pull requests, discussions, site `knot.tools`, canaux de bêta-test, et tout autre espace communautaire que nous hébergeons ou sponsorisons.

## Signalement

Pour signaler un comportement inacceptable, contactez :

- **`contact@knot.tools`** pour toute préoccupation générale liée au code de conduite
- **`security@knot.tools`** si le comportement comporte un risque de sécurité

Les signalements sont reçus par un humain réel, traités confidentiellement et accusés réception sous **72 heures** ouvrées. Nous appliquons les **lignes directrices d'application** du Contributor Covenant 2.1 (Correction → Avertissement → Bannissement temporaire → Bannissement permanent).

## Pourquoi adopter le Contributor Covenant

Adopter un standard largement compris signifie que les contributeurs et les personnes qui signalent savent exactement quel comportement est attendu et quel processus suivre. Maintenir notre propre texte ne ferait qu'ajouter de l'ambiguïté. Nous nous appuyons sur la version officielle maintenue par <https://www.contributor-covenant.org>.
