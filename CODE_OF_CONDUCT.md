# Code of Conduct

*🇬🇧 English · [🇫🇷 Lire en français](CODE_OF_CONDUCT.fr.md)*

The **Knot Tools** organisation has adopted the **Contributor Covenant 2.1** as its code of conduct.

The full text is published and maintained by the Contributor Covenant project:

- **English** : <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- **Plain text** : <https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt>
- **Translations** (40+ languages) : <https://www.contributor-covenant.org/translations/>

## Scope

This code applies to all spaces operated by the **knot-tools** organisation: GitHub repositories, issues, pull requests, discussions, the `knot.tools` website, beta-tester channels, and any other community space we host or sponsor.

## Reporting

To report unacceptable behaviour, please contact:

- **`contact@knot.tools`** for general code-of-conduct concerns
- **`security@knot.tools`** if the behaviour involves a security risk

Reports are received by a real human, treated confidentially, and acknowledged within **72 hours** on business days. We will follow the **enforcement guidelines** described in the Contributor Covenant 2.1 (Correction → Warning → Temporary Ban → Permanent Ban).

## Why we adopt the Contributor Covenant

Adopting a widely understood standard means contributors and reporters know exactly what behaviour is expected and what process to expect. Maintaining our own bespoke text would only add ambiguity. We rely on the upstream version maintained at <https://www.contributor-covenant.org>.
